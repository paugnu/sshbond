# SSHBond Support

Contact **info@yogabond.es** for help with SSHBond. Include your device model, operating system, app version and a description of the issue. Never send passwords, private keys or confidential terminal output.

SSHBond is an SSH client for servers you are authorized to access. Add a host with its address, port, username and password or key. Verify the server fingerprint using a trusted source before approving the first connection. Your server must be reachable from your device's network.

Android supports SSH terminals, ProxyJump chains and local, remote and dynamic port forwarding. iOS currently supports direct SSH terminals; ProxyJump and port forwarding are not supported. ProxyCommand and agent forwarding are not supported on either platform. SSHBond requires an installed native build; Expo Go cannot provide its SSH engine.

Private credentials are stored using the device Keychain or Keystore. The optional application lock requires biometrics configured on the device. Keep an independent backup of keys you need; device credentials are not a backup service.
